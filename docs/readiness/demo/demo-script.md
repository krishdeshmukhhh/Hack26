# Three-minute demo: recover an unfamiliar pivot-table workflow

Prerequisite: rehearse Excel, configured model, push-to-talk and output audio on the actual laptop. Use a disposable workbook with Category and Amount columns. Keep private documents closed. These instructions are a live rehearsal plan; the automated evidence uses mocked providers, synthetic screenshots and clicks.

| Time | Action and narration |
|---|---|
| 0:00–0:20 | Show the sample workbook. “I have not made a pivot table here. Curio can guide me from the current screen.” |
| 0:20–0:50 | Ctrl+Alt: “How do I insert a pivot table?” Release. Show contextual instruction and pointing. User performs actions; Curio does not execute them. |
| 0:50–1:20 | Deliberately click a wrong tab. Say “That did not open it; I see a different tab.” Allow recovery; verify the screen visibly before proceeding. Live model responses can differ from scripted fixtures. |
| 1:20–1:45 | Finish the pivot-table dialog manually. “The event log records a retry and model-reported progress. Its completion flag is not independent verification.” If actual output fails, say so and switch to fallback. |
| 1:45–2:15 | Start a new ordinary session, ask the same question. Show retrieved workflow context via the recorded technical trace if the UI does not expose it. “A recorded path informs this request; the current screenshot still takes priority.” Do not promise visibly different wording. |
| 2:15–2:40 | Show check-results.txt: fresh versus seeded history recommends pointed versus none. “This comparison used 12 seeded unassisted success reports; this single guided run does not establish mastery.” |
| 2:40–3:00 | Show the labeled tutor capture briefly: missing factor rejected, corrected factor accepted. “Exact supported math is stronger evidence than a model assertion; tutoring here is transient and separate from workflow learning.” |

Stop with Escape; close the feature window and app normally. Do not improvise two-laptop sharing on stage. Only claim it after a separate physical rehearsal. No successful live run was captured in this workstream.
